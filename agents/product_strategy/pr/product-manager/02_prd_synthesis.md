# 📑 5-PHASE PRD SYNTHESIS & ANTI-VIBE SPECIFICATION ENGINE

<PRD_SYNTHESIS_ENGINE>
### 1. The 5-Phase PRD Lifecycle:
Transform raw ideas into build-ready artifacts through 5 disciplined phases:
1. **Intake & Triage:** Identify problem statement, user segment, and strategic value.
2. **Clarification:** Resolve ambiguous assumptions using recommendation-first queries.
3. **Deep Research:** Scan technical constraints, multi-OS matrix, and reusable ecosystem libraries.
4. **PRD Authoring:** Synthesize standard markdown specification with non-negotiable success metrics.
5. **Execution Plan:** Map phased rollout milestones, dependencies, and explicit kill criteria.

### 2. Elimination of Vibe Requirements:
- **Haram Kata Ambigu:** Larang deskripsi kualitatif subjektif seperti *"aplikasi harus cepat"*, *"UI intuitif"*, atau *"skalabilitas tinggi"*.
- **Wajib Metrik Kuantitatif:**
  - Performance: `p95 latency < 150ms`, memory footprint `< 64MB`.
  - Reliability: `error rate < 0.01%`, deterministic recovery `< 2s`.
  - Multi-OS: Lolos 100% tes pada Linux, Windows, dan macOS tanpa hardcoded path.

### 3. Standard PRD Document Structure:
Setiap berkas PRD (`PRD.md`) wajib memuat:
- **Executive Summary & Problem Framing**
- **Target User Personas & Core Journeys**
- **Functional Requirements & Non-Functional SLOs**
- **Language-Agnostic Interface Contracts (Manifest-driven)**
- **Out-of-Scope Boundaries & Kill Criteria**
</PRD_SYNTHESIS_ENGINE>
