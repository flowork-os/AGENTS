# 🛡️ ANTI-AI-SLOP DEFENSE MATRIX & DISTINCTIVE UI ARCHETYPES

<ANTI_AI_SLOP_ENGINE>
### 1. HARD NEGATIVE CONSTRAINTS (INSTANT DISQUALIFICATION)
Eliminate cliché, generic "AI-slop" aesthetics across all generated user interfaces:
1. **NO SaaS-Card Kits:** Never chop every UI element into uniform rounded rectangles (`rounded-xl`) with hazy drop shadows. Group content using 1px crisp hairline dividers (`divide-y divide-zinc-800`), monolithic grid cells, or mathematical whitespace.
2. **NO AI-Purple Glow Meshes:** Strictly forbid purple/violet/pink neon gradient overlays (`from-purple-500 to-pink-500`) and ambient radial background blobs. Maintain a single functional accent (< 80% saturation) over authentic physical substrates.
3. **NO Symmetrical Centered Hero Defaults:** Prohibit centered H1 + subhead + dual buttons + floating mockup. Enforce dynamic asymmetry (60/40 or 70/30 split ratios, left-anchored typography with right-anchored active telemetry or canvas).
4. **NO Em-Dash Stylistic Crutches:** Zero em-dashes (`—` or `–`) anywhere in headlines, tags, or buttons. Use periods, colons, or standard hyphens.
5. **NO Hollow Div Screenshots:** Never simulate product UIs using colored empty `<div>` boxes. Always render authentic, functional interactive components or tables.
6. **NO Marketing Fluff Verbs:** Banned verbs: "Elevate", "Seamless", "Next-Gen", "Revolutionize", "Delve". Use concrete technical verbs: "Deploy", "Inspect", "Verify", "Ship".

### 2. COMMITMENT TO ONE DISTINCTIVE AESTHETIC ARCHETYPE
Declare and strictly commit to ONE archetype per surface. Never mix competing design paradigms:
- **Archetype A (Tactical Telemetry / Cyber-Matrix):** OLED Pitch Black (`#000000`), razor-sharp 1px lines (`#27272A`), zero border-radius (`rounded-none`), Phosphor Emerald (`#22C55E`) or Tactical Amber (`#F59E0B`), monospaced telemetry figures, and ASCII framing brackets `[SYS_ACTIVE]`.
- **Archetype B (Dark Mode OLED Studio):** Obsidian Zinc (`#09090B`), 1px borders with inner top highlight (`shadow-[inset_0_1px_0_rgba(255,255,255,0.12)]`), Neo-Grotesque sans typography, tactile `<kbd>` keycaps, and spring-damped micro-interactions.
- **Archetype C (Industrial Neobrutalism):** Unbleached Swiss paper (`#F4F4F0`), heavy 2px carbon black rules (`border-2 border-black`), zero radius, solid hard drop shadows (`shadow-[4px_4px_0px_#000]`), and Aviation Red (`#E61919`) accents.
- **Archetype D (Clean Studio / Editorial Atelier):** Warm bone substrate (`#FBFBFA`), charcoal text (`#111111`), hairline dividers (`#EAEAEA`), high-contrast editorial serif headers paired with geometric sans body, and generous breathing margins.
</ANTI_AI_SLOP_ENGINE>
